# Reaktionstest

Starte eine Runde und warte, bis das Feld grün wird. Wie viele Millisekunden brauchst du für den Klick? Wer zu früh drückt, muss neu starten. Deine beste Zeit bleibt sichtbar, solange die Seite geöffnet ist.

Zum Ausprobieren das Repository herunterladen und `index.html` im Browser öffnen. Das Spielfeld lässt sich auch mit der Tabulatortaste auswählen und mit Enter oder der Leertaste bedienen.

Die Zeitmessung steht in [script.js](./script.js) und verwendet `performance.now()`.
